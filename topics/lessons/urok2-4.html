Хімічні властивості етену. Методи одержання етену

📄 Теоретичний матеріал

Будова молекули етену

Етен (етилен) CH₂=CH₂ — найпростіший представник гомологічного ряду алкенів. Обидва атоми Карбону перебувають у стані sp²-гібридизації, молекула плоска, а подвійний зв'язок складається з однієї σ- та однієї π-сполуки. Саме π-зв'язок легко розривається в хімічних реакціях, тому етен значно реакційноздатніший за алкани.

Хімічні властивості етену

Через наявність подвійного зв'язку для етену характерні насамперед реакції приєднання — на відміну від алканів, для яких типові реакції заміщення.

Гідрування (приєднання водню)

Утворення етану CH₂=CH₂ + H₂ →(кат. Ni, Pt) CH₃–CH₃

Реакція відбувається за наявності каталізатора (нікель, платина чи паладій) і нагрівання.

Галогенування (приєднання галогенів)

Якісна реакція на подвійний зв'язок — знебарвлення бромної води CH₂=CH₂ + Br₂ → CH₂Br–CH₂Br (1,2-дибромоетан)

Швидке знебарвлення бромної води без нагрівання — характерна якісна реакція на кратний (подвійний або потрійний) зв'язок.

Гідрогалогенування

Приєднання гідроген хлориду CH₂=CH₂ + HCl → CH₃–CH₂Cl (хлоретан)

Гідратація (приєднання води)

Промисловий спосіб одержання етанолу CH₂=CH₂ + H₂O →(кат. H₃PO₄, t, p) CH₃–CH₂OH (етанол)

Реакція каталітичної гідратації етену — основний промисловий метод одержання етанолу.

М'яке окиснення розчином калій перманганату (реакція Вагнера)

Друга якісна реакція на подвійний зв'язок — знебарвлення розчину KMnO₄ 3CH₂=CH₂ + 2KMnO₄ + 4H₂O → 3CH₂OH–CH₂OH + 2MnO₂↓ + 2KOH

Розчин калій перманганату знебарвлюється, випадає бурий осад мангану(IV) оксиду, а з етену утворюється етиленгліколь — двоатомний спирт.

Повне окиснення (горіння)

Горіння в надлишку кисню C₂H₄ + 3O₂ → 2CO₂ + 2H₂O

Полімеризація

Утворення поліетилену nCH₂=CH₂ →(кат., t, p) (–CH₂–CH₂–)ₙ

Полімеризація — реакція з'єднання багатьох молекул етену (мономерів) у довгий ланцюг полімеру. Поліетилен — найпоширеніший у побуті пластик.

Способи одержання етену

1. Дегідрування етану

Проводиться за високої температури й каталізатора C₂H₆ →(кат., t°C) C₂H₄ + H₂

2. Дегідратація етанолу (лабораторний спосіб)

Нагрівання спирту з концентрованою сульфатною кислотою C₂H₅OH →(конц. H₂SO₄, t > 140°C) C₂H₄ + H₂O

3. Дегідрогалогенування галогеналканів

Нагрівання зі спиртовим розчином лугу CH₃–CH₂Cl + NaOH (спирт.) →(t) CH₂=CH₂ + NaCl + H₂O

4. Крекінг нафтопродуктів

У промисловості етен переважно добувають разом з іншими алкенами під час крекінгу — термічного розщеплення важких фракцій нафти на легші вуглеводні.

Застосування етену

  • Сировина для виробництва поліетилену — найпоширенішого пластику.
  • Промислове одержання етанолу (гідратація).
  • Одержання етиленгліколю — сировини для антифризів і синтетичного волокна лавсану.
  • Природний фітогормон — прискорює дозрівання плодів (наприклад, у сховищах для стимуляції дозрівання бананів і томатів).
