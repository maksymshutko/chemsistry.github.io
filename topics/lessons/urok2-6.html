Хімічні властивості етину. Методи одержання етину

📄 Теоретичний матеріал

Будова молекули етину

Етин (ацетилен) HC≡CH — найпростіший представник гомологічного ряду алкінів. Обидва атоми Карбону перебувають у стані sp-гібридизації, молекула лінійна (валентний кут 180°), а потрійний зв'язок складається з однієї міцної σ- та двох менш міцних π-сполук, розташованих у взаємно перпендикулярних площинах. Саме два реакційноздатні π-зв'язки роблять етин найактивнішим вуглеводнем серед розглянутих гомологічних рядів.

Хімічні властивості етину

Через наявність двох π-зв'язків етин здатний приєднувати реагенти у дві стадії — спочатку до алкену, потім до алкану (або відповідного похідного).

Гідрування (у дві стадії)

Повне насичення до етану HC≡CH + H₂ →(кат. Pd, Pt) CH₂=CH₂
CH₂=CH₂ + H₂ →(кат.) CH₃–CH₃

Галогенування — якісна реакція на потрійний зв'язок

Знебарвлення бромної води (у дві стадії) HC≡CH + Br₂ → CHBr=CHBr
CHBr=CHBr + Br₂ → CHBr₂–CHBr₂

Швидке знебарвлення бромної води без нагрівання — характерна якісна реакція на кратний (подвійний або потрійний) зв'язок.

Гідрогалогенування

Одержання вінілхлориду — мономеру для полівінілхлориду (ПВХ) HC≡CH + HCl →(кат.) CH₂=CHCl (хлоретен, вінілхлорид)

Гідратація — реакція Кучерова

Єдиний вуглеводень, що дає альдегід при гідратації — етин HC≡CH + H₂O →(кат. Hg²⁺, H₂SO₄) CH₃–CHO (етаналь)

Реакцію відкрив і дослідив у 1881 році український хімік Михайло Кучеров. Гідратація вищих алкінів (за правилом Марковникова) дає не альдегіди, а кетони — етин є винятком серед вуглеводнів.

Реакція заміщення — якісна реакція на кінцевий потрійний зв'язок

Утворення срібного ацетиленіду (жовтий осад) HC≡CH + 2AgNO₃ + 2NH₃ → AgC≡CAg↓ + 2NH₄NO₃

Атом Гідрогену біля кінцевого потрійного зв'язку має слабко виражені кислотні властивості (через високу частку s-орбіталі в sp-гібридизації) і здатний заміщуватися на йон срібла. Ця реакція дозволяє відрізнити термінальні алкіни від алкенів, для яких вона нехарактерна.

Окиснення розчином калій перманганату

Як і алкени, етин знебарвлює розчин KMnO₄ — ще одна якісна реакція на кратний зв'язок. Проте на відміну від алкенів (де утворюється двоатомний спирт), окиснення потрійного зв'язку відбувається глибше — з розривом карбонового ланцюга та утворенням карбонових кислот.

Горіння

Ацетилено-кисневе полум'я — до ≈3000°C 2C₂H₂ + 5O₂ → 4CO₂ + 2H₂O

Висока температура горіння етину використовується для автогенного зварювання й різання металів.

Тримеризація до бензену

Одержання ароматичної сполуки з алкіну (реакція М. Зелінського) 3C₂H₂ →(кат., t) C₆H₆

Способи одержання етину

1. Карбідний спосіб (класичний, лабораторний і промисловий)

Дія води на кальцій карбід CaC₂ + 2H₂O → C₂H₂↑ + Ca(OH)₂

Кальцій карбід, своєю чергою, одержують у промисловості з вапна й коксу при високій температурі в електропечах.

2. Піроліз метану

Високотемпературне розщеплення (сучасний промисловий спосіб) 2CH₄ →(≈1500°C) C₂H₂ + 3H₂

3. Дегідрогалогенування дигалогеналканів

Подвійне відщеплення гідроген галогеніду CH₂Br–CH₂Br + 2NaOH (спирт.) →(t) HC≡CH + 2NaBr + 2H₂O

Застосування етину

  • Автогенне зварювання й різання металів — ацетилено-кисневе полум'я.
  • Синтез вінілхлориду — мономеру для виробництва полівінілхлориду (ПВХ).
  • Синтез бензену та інших ароматичних сполук.
  • Одержання оцтового альдегіду (реакція Кучерова) — сировини для оцтової кислоти.
